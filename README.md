# AlternativePolyadenylationEngine

Alternative polyadenylation analysis pipeline for 3'UTR dynamics, polyA site usage, and cleavage site mapping.

## Features

- PolyA site identification and usage quantification
- 3'UTR length dynamics and shortening analysis
- Cleavage site sequence motif analysis
- Differential APA event detection across conditions
- Gene-level polyA site multiplicity assessment

## Results

100 samples × 3000 genes; Mean 3.47 polyA sites/gene; 3'UTR shortening=20% genes

## Usage

```bash
pip install numpy scipy matplotlib
python alternative_polyadenylation_engine.py
```
